## The idea

**Our Museum Passport** is a private, collaborative museum-discovery and review website for my girlfriend and me. It combines a forum-style feed with an interactive map where we can find museums, save places we want to visit, document completed visits, upload photographs, publish separate reviews, and build a shared record of the museums we have experienced together.

## Why

Museum locations, visit plans, photographs, personal notes, and ratings are normally scattered across mapping applications, messaging platforms, and phone galleries. This project brings them into one organized system while giving both users an equal voice through independent reviews and discussion threads. It will also let me apply application and systems integration concepts by connecting authentication, a database, media storage, an external place-search and mapping service, rating calculations, and a responsive web interface.

## Scope

The first version will support two private user accounts, museum search, an interactive map, museum markers, three visit states (**Want to Visit**, **Planned**, and **Visited**), and an independent **Favorite** flag. Users will be able to create visit posts, upload photographs, record the date and exhibition visited, submit independent museum-specific ratings, reveal a combined score after both users respond, comment on posts, react to experiences, maintain a wishlist, search and filter museums, and view basic visit statistics.

A museum and a visit will be stored separately so that the same museum can have several dated visits and review threads. The initial rating criteria will cover the collection, curation, atmosphere, visitor experience, accessibility, value, overall experience, and willingness to revisit.

Public registration, direct messaging, automatic ticket booking, turn-by-turn navigation, artificial-intelligence recommendations, a public social network, and three-dimensional museum navigation will be deliberately excluded from the first version.
